# 语音接入说明（IndexTTS2 本地配音）

本项目的语音能力**不依赖云厂商**：直接接本机的 IndexTTS2 服务（零样本克隆，
给一段 3~10 秒参考音频就能按那个音色念）。另可选用 VoxCPM2 的「音色设计」，
用一句中文描述造出参考音频——完全不需要现成音频。

接入点有三个，共用同一套后端客户端（`game_agent/assets/tts.py`）：

| 接入点 | 位置 | 用途 |
|---|---|---|
| Agent 配音工具 | `agents/tools/specialized.py::tts` | 跑 run 时 voice 角色产出真实配音（不是占位静音） |
| 语音工作台（界面） | 顶栏「语音」→ `frontend/src/pages/Voice.tsx` | 手动出配音、试音、造音色 |
| 对话朗读 | `pages/Chat.tsx` 每条回复下的「🔊 朗读」 | 让 agent 的回复被念出来 |

## 一、配置

`.env`（模板见 `.env.example`）：

```ini
# IndexTTS2 服务地址；空 = 未启用
TTS_BASE_URL=http://127.0.0.1:7860

# 默认音色：优先用预设名（IndexTTS2 服务端存的"参考音频+参数"）
TTS_PRESET=沙哑大叔
# 或者直接给参考音频文件路径（3~10 秒干声）
# TTS_REF_AUDIO=D:/assets/ref_4s.wav

# 情绪：0=沿用参考音色情绪(平) 1=情感参考音频 2=八维向量 3=文字描述情绪
# 只给音色参考音频、不配情绪时模型会用平静语气 → 台词一多就"三句一个调"
TTS_EMO_MODE=0
TTS_EMO_TEXT=            # mode=3 时的情绪描述，如「愤怒地质问」
TTS_EMO_WEIGHT=0.65      # 情绪强度 0~1
# TTS_EMO_VECTOR=0.9,0,0,0,0,0,0,0.1        # mode=2 时的 8 维权重：高兴,愤怒,悲伤,害怕,厌恶,忧郁,惊讶,平静
# TTS_EMO_AUDIO=D:/assets/emo_angry_4s.wav   # mode=1 时的情感参考音频（一段带目标情绪的干声）

# 单次合成等待上限（秒）：8G 单卡串行，首次含模型加载 30~60 秒
TTS_TIMEOUT_S=600

# 是否在界面暴露「音色设计」（需 IndexTTS2 侧装好 VoxCPM2）
GA_TTS_VOICE_DESIGN=true
```

IndexTTS2 侧的启动、接口、音色设计环境安装见它自己的
`docs/启动与接口说明.md`（`start_server.bat`、`install_voice_design.bat`、
`download_voice_design_model.bat`）。

**先起 IndexTTS2，再起本项目**：本项目启动时不连它，但界面顶栏的状态徽标会显示未连接。

### GPU 互斥：生图与配音共用一块显卡

本机 ComfyUI（生图）和 IndexTTS2（语音）**不能同时驻留显存**，否则 8G 卡直接 OOM。
后端内置调度器 `game_agent/assets/gpu_arbiter.py`：真正出图/出声时自动切换——

- 要**生图** → 先停 IndexTTS2 进程、等端口释放 → 拉起 ComfyUI → 出图；
- 要**配音** → 先停 ComfyUI 进程、等端口释放 → 拉起 IndexTTS2 → 合成；
- 进程内全局串行：并发的多个生成请求排队，不会两个一起抢卡；
- 切换点挂在 `comfyui.generate_images_bytes` 和 `tts.synthesize`（含音色设计）上，
  所以一个 run 里先出图再配音也能自动来回切，不需要上层协调。

代价：每次切换对方服务都要重新加载模型（ComfyUI 约 30~60 秒、IndexTTS2 约 3~10 秒），
所以尽量把同一类生成放在一起做。想关掉（例如两块卡各跑一个）：`.env` 里设

```ini
GA_GPU_EXCLUSIVE=false
GA_GPU_STOP_TIMEOUT_S=45   # 停掉对方后最多等多少秒让显存释放
```

## 二、给 agent 用（配音角色出真实音频）

1. 配置页 → 供应商，新增一条 **音频 / voice** 档位，驱动选
   **「IndexTTS2 本地部署」**，填：
   - `base_url`：`http://127.0.0.1:7860`
   - `preset`：音色预设名（如 `沙哑大叔`），或改填 `reference_audio` 给参考音频路径
   - `emo_mode`：`0`/`1`/`2`/`3`（见「四、情绪控制」）；按模式补 `emo_text` / `emo_vector` / `emo_audio`
2. 把这个档位绑给**配音角色**（角色级媒体档位，image→美术、audio→配音）。
3. 之后 run 里配音角色调用 `tts` 工具，就会走到 IndexTTS2 出真音频，
   产物落在 `<工作区>/assets/audio/voice/<slug>.wav`，并登记为 artifact。

失败时（服务没起、音色不存在）**回退占位静音 wav**，行为和老版本一致，
不会让整个 run 挂掉；但 run 会被标记 `has_placeholder`，方便事后一键重画。

工具入参也支持临时覆盖情绪与音色：
`{"text": "...", "slug": "yuejian_ult", "preset": "月见", "emo_text": "冷冷地嘲讽"}`
（或 `emo_vector=[...]` / `emo_audio="<工作区相对路径>"`）。

## 三、给界面用（语音工作台）

顶栏 →**语音**。功能：

- **音色**：下拉选 IndexTTS2 预设；或「＋ 上传参考音频」临时用一段自己的音频
  （一次性，不落库；服务端存到 `~/.trace/objects/voicegen/uploads/`）
- **情绪**（四种，见下方「情绪控制」一节）：
  沿用参考音色（平）/ 情感参考音频 / 八维情感向量 / 文字描述情绪
- **生成语音** → 右侧出播放器 + 下载；下方保留本次会话的生成记录（可回放）
- **音色设计**（折叠区）：写一句描述（如「三十岁左右的成熟女性，声音微哑慵懒，
  尾音带笑，语速偏慢」）+ 试听台词 + 候选条数 → 生成 → 试听后「存为预设」，
  存完自动切到该预设，直接就能合成。

文本会自动清洗：Markdown 的 `**`、`` ` ``、`#`、列表符号、链接语法都会剥掉，
只念人话（所以对话里的「朗读」可以直接丢整段回复进来）。

## 四、情绪控制（为什么"三句一个调"）

IndexTTS2 的**音色参考音频只决定音色，不决定情绪**。只给音色音频而不指定情绪时，
模型会用**平静语气**念——这就是同一角色多条台词听起来"一个调、没感情"的根因。
加情绪有三条独立通路（服务端 `/api/v1/tts` 的 `emo_mode`）：

| 模式 | 素材 | 说明 |
|---|---|---|
| `0` | 无（同参考） | 沿用音色参考音频自带的情绪；单条干声通常就是"平" |
| `1` | `emo_audio` 情感参考音频 | 另给一段**带目标情绪**的干声，用它的情绪念这段文本 |
| `2` | `emo_vector` 八维向量 | 直接调权重：**高兴,愤怒,悲伤,害怕,厌恶,忧郁,惊讶,平静**（各 0~1，总和 ≤0.8 最稳） |
| `3` | `emo_text` 文字描述 | 如「愤怒地质问」「温柔地哄」，服务端用 Qwen 做情感分析转成向量 |

`emo_weight`（0~1，默认 0.65）是**强度**：对 mode 1/2 会缩放情感；mode 3 仅在未显式给向量时作为强度。

三个接入点都支持：

- **语音工作台**：情绪下拉选 0/1/2/3——选 1 出现「选择情感音频」上传框；选 2 出现 8 个权重滑块；
  选 3 出现情绪描述输入框。生成结果下方会显示本次实际生效的模式。
- **对话朗读**：每条回复下的「🔊 朗读」旁有「情绪：…」选择器——默认「自动」（不给素材，
  用这条回复本身的文字让服务端 Qwen 判情绪，走的是下面的 `emo_auto`），也可选
  平静 / 八维向量（高兴、愤怒… 单维拉高）/ 文字描述 / 情感参考音频。选择写进 localStorage；
  情感音频是本地 File、仅本次页面有效，刷新回「自动」。请求体加 `emo_auto: true` 即可复现「自动」。
- **Agent 工具**：`generate_audio(text=..., voice=..., emo_text="愤怒地质问")`
  或 `emo_vector=[0.9,0,0,0,0,0,0,0]` 或 `emo_audio="assets/audio/emo/angry.wav"`（工作区相对路径）。
  也可以在音频档位 params 里固定 `emo_mode/emo_text/emo_vector/emo_audio`，条目入参可覆盖。
- **预设**：上传音频存预设时一并带 8 维向量 / 情感音频，之后按名字复用该音色时情绪也一起复现。

> `emo_auto`（对话朗读「自动」用）：没给任何情绪素材时，自动拿**待念文本本身**当 `emo_text`
> 走 mode 3（服务端 Qwen 分析），既不引入新依赖、也不会再退回平静腔；显式给了 mode/素材时它不生效。
> 服务端情感文本上限 500 字，长回复只取前 480 字做语气判断（整段仍按原文念）。

> 批量配音台词多、角色情绪要区分时，最省事的做法：一个角色一个预设 + 每条台词给
> `emo_text`。纯"念得平"多半就是只给了音色、忘了给情绪。

## 五、接口

所有接口都需要登录态（`Authorization: Bearer <PAT>` 或 Cookie）并带 `X-Team-Id`：

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/api/voice-gen/status` | view | 服务是否可达、模型是否已加载、预设列表、音色设计是否可用 |
| POST | `/api/voice-gen/upload` | run:create | multipart 上传参考音频（≤20MB，wav/mp3/m4a/flac/ogg） |
| POST | `/api/voice-gen` | run:create | 合成：`{text, preset, reference, emo_mode, emo_text, emo_weight, emo_vector, emo_audio, emo_auto, label}` |
| GET | `/api/voice-gen/files/{name}` | download | 取合成结果（audio/wav） |
| POST | `/api/voice-gen/design` | run:create | 音色设计：`{desc, say, n}` → 候选列表 |
| GET | `/api/voice-gen/design/files/{name}` | download | 取候选音频 |
| POST | `/api/voice-gen/presets` | run:create | 候选存为预设 `{name, file, overwrite}` |

`POST /api/voice-gen` 返回：

```json
{"file":"vc_20261027_004452_e2e_813265.wav",
 "url":"/api/voice-gen/files/vc_20261027_004452_e2e_813265.wav",
 "elapsed_ms":21798,"server_elapsed_s":21.69,"size":338988,
 "preset":"沙哑大叔","chars":38,"used_text":"（清洗后实际送进 TTS 的文本）"}
```

最快验证（PowerShell）：

```powershell
$h = @{ Authorization = "Bearer $env:GA_PAT"; "X-Team-Id" = $env:GA_TEAM }
Invoke-RestMethod "http://127.0.0.1:8765/api/voice-gen/status" -Headers $h
Invoke-RestMethod "http://127.0.0.1:8765/api/voice-gen" -Headers $h -Method Post `
  -ContentType "application/json" -Body '{"text":"测试一句"}'
```

> 没有 PAT 时：用页面账号登录一次即可用 Cookie；或写个小脚本调
> `AuthService.create_pat(user_id, "cli", ["*"])` 造一个。

## 六、性能与限制（实测，RTX 3060 Ti 8G）

- 单句 20~60 秒；首次调用先加载模型 +30~60 秒（页面状态徽标会从"待加载"变"已加载"）。
- **串行**：单卡一把推理锁，并发请求只会排队；`409` 表示服务端正忙。
- **音色设计会打断合成**：它需要先卸载 IndexTTS2 腾显存（8G 放不下两个模型），
  所以设计完第一次合成会重新加载。批量作业请先设计音色、再批量合成。
- 参考音频 3~10 秒干声最好；超过 15 秒服务端会截断。48k 也行（内部重采样）。
- 输出固定 22.05kHz 单声道 wav，和 IndexTTS2 的产物一致。

## 七、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 状态显示「语音服务未连接」 | IndexTTS2 没起，或 `TTS_BASE_URL` 写错；先 `start_server.bat` |
| 生成报 502 + `连不上语音服务` | 同上；本服务只做转发，不代管它的生命周期 |
| 生成报「没有可用音色」 | 服务端一个预设都没有 → 用「音色设计」造一个，或上传参考音频 |
| `音色设计已关闭` | `.env` 里 `GA_TTS_VOICE_DESIGN=false` |
| 音色设计报 `环境未就绪` | IndexTTS2 侧没装 VoxCPM2：跑 `install_voice_design.bat` + `download_voice_design_model.bat` |
| 401 未登录 | PAT 过期/被清库；重新登录或用 `AuthService.create_pat` 造新的 |
| 403 权限不足：需要 run:create | 当前角色是 viewer；换 developer 及以上 |
| 念出来有符号噪音 | 文本没走清洗（直接调 IndexTTS2 才会）；本项目接口会自动清 |
| 台词都是一个调、没感情 | 只给了音色参考音频（emo_mode=0，平）。用 emo_text / emo_vector / emo_audio 指定情绪（见「四、情绪控制」） |
| 选了「文字描述情绪」但还是平 | emo_text 为空会回落 0；确认填了描述，且 emo_weight 不是 0 |
