========================================================
 Trace · Windows lite 单机部署包
========================================================

本包为「lite 单机模式」：单进程（API + 执行器一体），
默认用 SQLite（零安装数据库）+ 内置前端页面，浏览器即用。

--------------------------------------------------------
一、目标机要求
--------------------------------------------------------
- Windows 10 / 11，64 位
- Python 3.12 或更高（安装时务必勾选 "Add Python to PATH"）
  * 如果包内已经带了 .venv 目录，则无需另装 Python。
- 可联网（首次装 Python 依赖需要；除非包内附了 wheels/ 或 .venv）
- 一个可用的 LLM 接口（OpenAI 兼容协议）：API Key + Base URL + 模型名

【无需 PowerShell、无需手敲命令】安装/启动/停止全部是双击 .cmd 文件完成。
（setup.cmd 内部会自动调用 Python；只有你机器上没装 Python 时，
  它才会提示你去 python.org 装系统 Python——这一步其余全自动。）

--------------------------------------------------------
二、三步启动
--------------------------------------------------------
1) 把本 zip 解压到一个固定目录（路径尽量不要有中文/空格，
   例如 D:\Trace）。

2) 双击  setup.cmd  安装依赖（自动建 .venv、装依赖，无需 PowerShell、
   无需手敲命令）。首次会联网下载，几分钟；窗口里能看到进度。
   * 若公司网络慢，用镜像：右键 setup.cmd -> 编辑，把第一行参数改成
     你的镜像地址后用命令行运行：
       setup.cmd https://pypi.tuna.tsinghua.edu.cn/simple
     （或先在系统里设 HTTPS_PROXY 再双击 setup.cmd）
   * 之后 start.cmd 首次启动若发现没装依赖，也会自动调用 setup.cmd。

3) .env（setup 已自动生成）可以先留空，启动后在界面里配模型（推荐）：
     设置 → 模型配置：加一个供应商（填地址 + Key）；
     设置 → 智能体：把「对话模型」绑到该档位，即时生效、不用重启。
   也可在 .env 里用全局兜底（不想进界面配时）：
     OPENAI_API_KEY=你的key
     OPENAI_BASE_URL=https://你的中转或官方/v1
     GA_LLM_MODEL=模型名
   然后双击  start.cmd  启动。
   浏览器会自动打开 http://127.0.0.1:18888/

4) 首次使用：直接用内置示例账号登录
       邮箱：demo@local
       密码：demo1234
   （本包首次启动会自动创建该示例 owner + 示例项目，启动窗口也会打印这组账号。）
   * 想用你自己的账号：登录后在「团队 / 设置」里新建成员或改密码；
     也可以把 .env 里的 GA_SEED_DEMO 删掉，改用
     http://127.0.0.1:18888/setup + 启动窗口打印的一次性引导 token 建首个 owner。

--------------------------------------------------------
三、.env 关键项说明
--------------------------------------------------------
- GA_MODE=lite                      运行模式（不要改）
- DATABASE_URL=                     留空 = 用内置 SQLite（本版本只支持 SQLite）
- GA_HOST=127.0.0.1                 仅本机访问
- GA_PORT=18888                      端口
   → 要让局域网其他电脑访问：GA_HOST=0.0.0.0，并在 Windows 防火墙放行 18888
- GA_DATA_DIR=                      数据目录（见第四节），留空默认 %USERPROFILE%\.trace
- GA_MAX_CONCURRENT_RUNS=3          同时执行的任务数
- GA_SECRET_KEY=                    生产建议设随机长字符串

--------------------------------------------------------
四、数据保存在哪（备份就拷这个目录）
--------------------------------------------------------
默认：C:\Users\<你>\.trace\
   game_agent.db        数据库（SQLite）
   projects\            各项目工作区（被 Agent 修改的文件）
   run_snapshots\       每次改动的写前快照（审阅/回滚用）
   logs\                运行日志
想换位置：在 .env 里设 GA_DATA_DIR=D:\TraceData（换机搬家时整个目录拷走即可）

--------------------------------------------------------
五、可选增强（不装也能用，只是对应功能降级）
--------------------------------------------------------
- 本地生图 ComfyUI：.env 里 COMFYUI_BASE_URL=http://127.0.0.1:10188
     （未配置则出「占位图」）
- 本地语音 IndexTTS2：.env 里 TTS_BASE_URL=... 与 TTS_HOME=<安装目录>
     （未配置则配音回退占位静音）
- 网页截图验收 screenshot_page：需要本机有 Chrome 或 Edge
     （自动探测；否则设 GA_BROWSER_PATH 指向 chrome.exe）
- 音视频转换：需要 ffmpeg / ffprobe 在 PATH 里
- MCP 工具：需要 Node.js(npx) 与 mcp 包（install 已尝试安装 mcp）
- 图像与语音若共用一张显卡：保持 GA_GPU_EXCLUSIVE=true（自动互斥）

--------------------------------------------------------
六、停止 / 重启
--------------------------------------------------------
- 忘记密码：双击 start.cmd，在菜单里选 [2] Reset a password（无需旧密码）
- 停止：双击 stop.cmd（只结束本目录的 Trace 进程，不影响其他程序）
- 重启：再次双击 start.cmd
- 直接用 Ctrl+C 关掉启动窗口也可以停止服务

--------------------------------------------------------
七、常见问题
--------------------------------------------------------
1) 双击 setup.cmd 后窗口一闪而过 / 提示找不到 Python
   → 本机没装 Python 3.12+。到 https://www.python.org/downloads/ 安装，
     安装时务必勾选 "Add python.exe to PATH"，然后重新双击 setup.cmd。

2) 启动后浏览器显示 “未连接 / 无法访问”
   → 看启动窗口是否有 Python 报错；确认 18888 端口没被占用：
     netstat -ano | findstr :18888
   → 若刚启动，等 3~5 秒再刷新。

3) 对话报 LLM 401/403 或 “Key 无效”
   → 检查 OPENAI_API_KEY / OPENAI_BASE_URL / GA_LLM_MODEL；
   → 中转站若挂在 Cloudflare 后面，代码已默认带浏览器 UA，一般无需额外设置。

4) 想给局域网同事用
   → .env 设 GA_HOST=0.0.0.0，防火墙放行 18888，同事访问 http://<本机IP>:18888

5) 数据库相关报错
   → 本版本只用 SQLite，无需安装数据库服务；确认 .env 里 DATABASE_URL 为空或 sqlite+aiosqlite:///…。

--------------------------------------------------------
八、升级
--------------------------------------------------------
保留你的 .env 与数据目录（第四节的 .trace），
把旧程序目录里除 .env 外的文件替换为新包内容，重新双击 setup.cmd 即可。
（数据库结构会在启动时自动补列迁移，无需手动操作）
