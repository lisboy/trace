========================================================
 Trace · Windows 单文件 EXE 版（无需安装 Python）
========================================================

这是一个自带运行时的单文件程序：目标机【不需要】装 Python，
也不需要联网 pip 安装依赖。双击即可运行。

--------------------------------------------------------
一、目标机要求
--------------------------------------------------------
- Windows 10 / 11，64 位
- 无需安装 Python、无需 PowerShell、无需联网装依赖
  （首次启动会把运行时解压到临时目录，约慢 2~5 秒，之后正常）
- 一个可用的 LLM 接口（OpenAI 兼容协议）：API Key + Base URL + 模型名

--------------------------------------------------------
二、三步启动（全是双击，无需命令）
--------------------------------------------------------
1) 把本 zip 解压到一个固定目录（路径尽量不含中文/空格，
   例如 D:\Trace）。

2) 双击  start.cmd
   * 首次运行若没有 .env，会自动用 env.template 生成并用记事本打开：
     可以直接留空，启动后在界面里配（推荐）：
       设置 → 模型配置：加一个供应商（填地址 + Key）；
       设置 → 智能体：把「对话模型」绑到该档位，即时生效、不用重启。
     也可在 .env 里用全局兜底（不想进界面配时）：
        OPENAI_API_KEY=你的key
        OPENAI_BASE_URL=https://你的中转或官方/v1
        GA_LLM_MODEL=模型名
   * 保存后再次双击 start.cmd 即可启动。
   * 浏览器会自动打开 http://127.0.0.1:18888/

3) 首次使用：直接用内置示例账号登录
       邮箱：demo@local
       密码：demo1234
   （本包首次启动会自动创建该示例 owner + 示例项目，启动窗口也会打印这组账号。）
   * 想用你自己的账号：登录后在「团队 / 设置」里新建成员或改密码；
     也可以在首次启动前，把 .env 里的 GA_SEED_DEMO 删掉，改用
     http://127.0.0.1:18888/setup + 启动窗口打印的一次性引导 token 建首个 owner。

忘记密码：双击 start.cmd，在菜单里选 [2] Reset a password（无需旧密码），
  或在命令行运行：Trace.exe --reset-password

停止服务：双击 stop.cmd（只结束本目录的 Trace.exe）。

--------------------------------------------------------
三、文件说明
--------------------------------------------------------
  Trace.exe   主程序（自带 Python 运行时与全部依赖）
  start.cmd       启动（双击）
  stop.cmd        停止（双击）
  env.template    配置模板（首次启动会复制成 .env）
  .env            你的配置（首次启动后生成，需自己填 LLM）

--------------------------------------------------------
四、数据保存在哪（备份就拷这个目录）
--------------------------------------------------------
默认：C:\Users\<你>\.trace\
   game_agent.db        数据库（SQLite）
   projects\            各项目工作区
   run_snapshots\       每次改动的写前快照
   logs\                运行日志（exe.out 是程序输出）
想换位置：在 .env 里设 GA_DATA_DIR=D:\TraceData（搬家时整个目录拷走即可）

--------------------------------------------------------
五、可选增强（不装也能用，只是对应功能降级）
--------------------------------------------------------
- 本地生图 ComfyUI：.env 里 COMFYUI_BASE_URL=http://127.0.0.1:8588
- 本地语音 IndexTTS2：.env 里 TTS_BASE_URL=... 与 TTS_HOME=<安装目录>
- 网页截图验收：需要本机有 Chrome 或 Edge（自动探测；否则设 GA_BROWSER_PATH）
- 音视频转换：需要 ffmpeg / ffprobe 在 PATH 里
- MCP 工具：需要 Node.js(npx)；mcp 客户端已内置在 exe 里
- 生图与语音共用一张显卡：保持 GA_GPU_EXCLUSIVE=true（自动互斥）

--------------------------------------------------------
六、常见问题
--------------------------------------------------------
1) 首次运行 Windows 提示“已保护你的电脑 / SmartScreen”
   → 点“更多信息” -> “仍要运行”。（程序未做数字签名，属正常现象）

2) 杀毒软件误报
   → PyInstaller 打包的程序偶被误报，加白名单即可。

3) 启动后浏览器显示“未连接 / 无法访问”
   → 看黑窗口有无报错；确认 18888 端口没被占用：
     netstat -ano | findstr :18888
   → 刚启动等 3~5 秒再刷新。

4) 对话报 LLM 401/403 或“Key 无效”
   → 检查 OPENAI_API_KEY / OPENAI_BASE_URL / GA_LLM_MODEL。

5) 想给局域网同事用
   → .env 设 GA_HOST=0.0.0.0，防火墙放行 18888，访问 http://<本机IP>:18888

6) 日志在哪
   → %USERPROFILE%\.trace\logs\（exe.out 为程序标准输出）

--------------------------------------------------------
七、升级
--------------------------------------------------------
保留你的 .env 与数据目录（.trace），
用新版 Trace.exe 直接替换旧的即可（数据库结构启动时自动迁移）。
如果新版新增了对 env.template 的字段，按提示把新字段补到你的 .env。
